SISTEM COMPUTER VISION DETEKSI KESIAPAN PANEN KANGKUNG AQUAPONIK

Bed Aquaponik 2 m x 1,1 m • Grid 4x6 (24 Zona) • Segmentasi HSV Adaptif • PSI 0-100
Raspberry Pi 4B + Kamera CSI IR 5MP • Firebase Dashboard • Enclosure 3D-Print PETG
Computer Vision Kelayakan Panen per Zona Kesehatan Daun Pi + Dashboard Web
Tujuan
Mempermudah petani untuk melihat kelayakan panen tanaman dan kesehatan daun perzona secara objektif, real-time, dan konsisten.
Solusi
Sistem sensor tanaman otomatis berbasis Computer Vision yang memotret bed setiap 10 menit, membagi jadi 24 zona, dan memberikan peta kesiapan panen serta kesehatan daun secara real-time ke dashboard.
Metode (Pipeline Computer Vision)
TahapTeknikFungsi
1Canny Edge + HomografiDeteksi otomatis tepi bed dan warp perspektif
2Grid 4x6Pembagian bed menjadi 24 zona pemrosesan
3HSV Adaptif (f = mean(V)/128)Stabilisasi coverage lintas kondisi cahaya (+-38%)
4Segmentasi WarnaHijau = tanaman, Kuning = klorosis, Coklat = nekrosis
5EMA alpha = 0,2Stabilisasi temporal (jitter turun -53%)
6PSI = 100 x (0,5 x Y + B) / NIndeks stres tanaman sebagai input kontroler fuzzy
Hardware
KomponenSpesifikasi
KomputerRaspberry Pi 4B (2 GB), Debian 13, Python 3.13
KameraCSI IR 5MP (ov5647) via libcamera/Picamera2
EnclosurePETG 3D-Print, IP65, sun shield, cable gland, silica gel
MountingLengan miring, top-down ~2,5 m di atas bed
DayaAdaptor 5 V / 3 A, microSD high-endurance 16 GB
JaringanWiFi + Tailscale (remote tanpa buka port)
Arsitektur Sistem
Kamera CSI → CV (OpenCV) → Grid 4x6 → PSI → JSON (2-3 KB)
↓ ↓
Firebase Firestore ← Web Dashboard (heatmap 4x6 + grafik 24 jam)
↓
Kontroler Fuzzy → Pompa Air (ESP32)

Pi hanya mengirim data (tidak melayani koneksi masuk). Outbox antrean saat offline.
